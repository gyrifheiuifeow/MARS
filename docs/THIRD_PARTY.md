# Third-party components

The runtime trees include modified headers from
[RaBitQ-Library](https://github.com/VectorDB-NTU/RaBitQ-Library), under Apache-2.0.
The license text is in `licenses/RaBitQ-Library-LICENSE`.

Eigen and hnswlib carry their notices under each runtime's
`src_tree/baselines/RaBitQ-Library-main/include/rabitqlib/third/` directory.
Retain those notices when redistributing the dependencies.

Use the supplied headers to reproduce the saved runs, including the baseline
HNSW retry patch. The provenance manifest records their versions and hashes.
